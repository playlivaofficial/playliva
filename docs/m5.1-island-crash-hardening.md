# M5.1 — Island Crash visual and delivery hardening

M5.1 is a presentation and delivery pass over the merged M5 game. It does not
change the Crash engine, payout math, wallet/session contract, localization,
GEO eligibility, operator records, affiliate destinations, analytics, sitemap
scope or public route set.

## Presentation changes

- The fixed mobile site nav is omitted only on localized `/play/crash` routes.
  The game keeps one clear primary action and the rest of the mobile navigation
  remains unchanged.
- A narrower camera field of view and aspect-aware camera distance make the two
  supplied characters materially larger on desktop while retaining the tested
  1.45 world scale and exact source-animation contact marker.
- Post-contact presentation now moves the castaway clear of the kicker before
  the flying clip takes over. Impact reaction crossfade is 110ms; other normal
  crossfades are 180ms and reduced-motion fades are 60ms.
- Flight uses a forward launch, restrained multi-frequency bob/weave, subtle
  rotation and multiplier-responsive scenery speed. The castaway stays fully
  inside the narrow frame and to the right of the multiplier.
- The procedural scene adds a sun, more depth-distributed palms, slightly richer
  scenic islanders and additional wind streaks without adding runtime downloads.
- The former torso-height torus is replaced by a short ground impact ring and
  three head-aligned daze markers. Crash placement keeps the grounded body inside
  the mobile frame, and the result chip moves to an open lower-left area.

## Asset delivery

The eight immutable source GLBs are committed under
`assets-source/originals/crash/characters/`. The generator reads from that path;
only `public/originals/crash/runtime/` is web served. The manifest-backed test
checks all source hashes and exact sizes and fails if the old public source path
exists.

| Payload | Exact bytes |
| --- | ---: |
| Eight non-public source GLBs | 135,344,240 |
| Runtime castaway | 3,725,264 |
| Runtime kicker | 3,762,916 |
| Runtime total | 7,488,180 |

## Local browser acceptance

At 320×720, the document has equal 305px client/scroll widths, the game viewport
is 279×260px, and the 247×60px primary action is fully visible at y=639–699 with
no fixed bottom nav. At 1280×720 the 927×380px game viewport and 288×76px action
remain fully visible; the fullscreen composition keeps the game, controls,
settings, activity and Play Real surface useful for stream capture. Ready, kick,
flight and crash frames were inspected with textured characters loaded.

The optimized local production origin returns 200 for the English, Portuguese
and Spanish Crash routes, 404 for unknown play slugs and 404 for the former
public source-GLB path. Runtime GLBs return 200 with their exact manifest sizes.
The existing eligible Brazil Play Real CTA remains a `_blank` sponsored,
noopener/noreferrer `/go` link; `/go` still returns the configured 302 plus
`noindex, nofollow` without changing any partner record or destination.

Local production measured 5,476,320 same-origin transfer bytes through the first
character frame, including 4,982,851 encoded character bytes and 366,257 encoded
JavaScript bytes. Character decode/load to the first rendered frame was 323ms;
the first 180 visible frames had a 16.8ms 95th-percentile interval.

These are local desktop browser observations, not physical low-end Android,
touch, vibration, audio-level or network-latency certification. Release status,
hosted CI and production deployment must be reported from their actual systems.
